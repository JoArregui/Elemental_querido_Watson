# Elemental, querido Watson

> Ver documentación definitiva en [`DOCUMENTACION.md`](DOCUMENTACION.md) — única fuente de verdad del proyecto (434 líneas, consolidada 2026-09-23).

Biblioteca de casos de Sherlock Holmes y el Dr. Watson: 6 libros-etapa interactivos (90 páginas, 1 acertijo por página), con audiolibro, pistas progresivas, finales ramificados, coleccionables y secretos.

- **Stack**: Flutter `^3.11.5`, `flutter_bloc ^9.1.1`, `get_it`, `shared_preferences`, `flutter_tts`, `audioplayers`, `share_plus`.
- **Arranque**: `flutter pub get && flutter analyze && flutter test`
- **Icono**: `dart run flutter_launcher_icons` desde `assets/Icono_Watson.jpg`
- **Ramas**: `main` → `develop` → `feat/<codigo>` (ver `DOCUMENTACION.md` §16 y §18)

Toda la información detallada (arquitectura, modelos, BLoCs, persistencia, UI, servicios, i18n, assets, gamificación, roadmap y estado) está en `DOCUMENTACION.md`.
